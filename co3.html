CO3 Unit III · Differential GPS

Differential GPS (DGPS)

Course Outcome

CO3: Know the use of DGPS and its applications and advantages.

Introduction

Standalone GPS position fixes carry several metres of error from satellite clock, orbit, and atmospheric effects. Differential GPS (DGPS) is a technique that removes most of these errors by comparing observations from two receivers, boosting positioning accuracy from several metres down to sub-metre or even centimetre level — essential for engineering-grade surveying.

Differential Correction Principle

DGPS uses a base station set up on a point whose exact coordinates are already known, and one or more rover receivers moving over the area to be surveyed. Because both receivers see largely the same satellites through nearly the same atmosphere, most error sources (satellite clock, ephemeris, ionospheric and tropospheric delay) affect them almost identically.

The base station computes the difference between its known position and the position GPS alone gives it — this difference is the correction. That correction is transmitted to the rover and applied to the rover's own GPS solution, cancelling out the shared error.

DGPS Working — Real-Time vs Post-Processed

  • Real-time DGPS: The base station broadcasts corrections continuously (e.g. via RTCM radio link, mobile data, or satellite) and the rover applies them instantly, giving corrected coordinates in the field immediately.
  • Post-processed DGPS: Both base and rover simply log raw data; corrections are computed and applied afterwards in office software. Useful when no real-time communication link is available.

Control Station Set-up

Setting up a reliable base/control station is critical to DGPS accuracy:

  1. Choose a stable, open-sky location free from overhead obstructions and multipath sources (buildings, metal structures, water bodies).
  2. Occupy a point with known or precisely surveyed coordinates — ideally an existing benchmark or a point observed for an extended session.
  3. Level and centre the receiver antenna accurately, and record antenna height.
  4. Log data continuously for the duration of the rover's survey session so corrections are available throughout.

Loop Closure

To verify the accuracy of a control traverse, surveyors use the loop closure technique: the traverse starts and ends at the same known control point (or two known points). Since the true coordinates of the start/end point are known, any difference between the computed and known values — the misclosure error — reveals the accumulated error in the survey. This misclosure is then distributed proportionally across all traverse stations (e.g. by the Bowditch/compass rule) to produce adjusted, self-consistent coordinates.

Advantages Over Standalone GPS

ParameterStandalone GPSDGPS
Typical accuracy5–10 mSub-metre to a few centimetres
Error cancellationNoneCancels satellite clock, ephemeris, ionospheric/tropospheric error
Suitability for engineering surveyReconnaissance onlySuitable for control and detail surveys
Applications

DGPS is widely used for topographic and cadastral surveys, precision agriculture, marine navigation and dredging, and as the reference correction source for RTK GPS surveying.
